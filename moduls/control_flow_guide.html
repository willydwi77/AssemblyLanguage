Arsitektur:

Register EFLAGS & Anatomi Percabangan (IF/ELSE)

Di tingkat Assembly, tidak ada perintahif (a == b). CPU harus melakukan dua langkah terpisah: Pertama, melakukan perbandingan fisik (pengurangan matematika) dan menyimpan statusnya di register khusus bernamaEFLAGS / RFLAGS. Kedua, melakukan evaluasi berdasarkan status tersebut untuk memutuskan apakah CPU harus "melompat" (Jump) ke blok memori lain.

Register EFLAGS (Status Bits)

InstruksiCMP A, Bsecara harfiah menghitung(A - B). Hasilnya langsung dibuang, tetapi efeknya mengubah bendera (Flags) berikut:

FlagKepanjanganKapan Aktif (Bernilai 1)?
ZFZero FlagJika hasil operasi adalahNol. Artinya,A == B.
SFSign FlagJika hasil operasiNegatif. Artinya,A < B.
CFCarry FlagJika terjadi "pinjam/simpan" pada operasi *unsigned* (aritmatika tanpa tanda).
OFOverflow FlagJika terjadi limpahan nilai pada operasi *signed* (positif/negatif ekstrem).
Instruksi JUMP Berdasarkan Status

Instruksi ini membaca Flag di atas, lalu memanipulasi registerInstruction Pointer (EIP/RIP)untuk mengubah alur pembacaan instruksi.

Konvensi Pemanggilan (Calling Conventions)

Dalam ekosistem32-bit (x86), pengiriman parameter untuk fungsi sangat mengandalkan tumpukanStack. Pertanyaannya: Sesudah fungsi selesai dieksekusi,siapa yang bertugas membersihkan tumpukan argumen tersebut dari Stack?Hal ini melahirkan beberapa konvensi standar.
Dalam ekosistem64-bit (x64), terutama di sistem Windows (Microsoft x64 ABI), pengiriman argumen sangat mengandalkanRegisterketimbang Stack untuk 4 argumen pertama, demi kecepatan maksimal. Semua tumpukan memori (*shadow space*) dibersihkan oleh pemanggil (*Caller*).
Tiga Aturan Utama x86
KonvensiCara Kirim ArgumenPembersih Stack (Cleanup)
__cdeclSemua di-PUSH ke Stack (kanan ke kiri)Caller (Pemanggil)
__stdcallSemua di-PUSH ke Stack (kanan ke kiri)Callee (Fungsi Tujuan)
__fastcall2 Argumen pertama di ECX, EDX. Sisanya di Stack.Callee (Fungsi Tujuan)

* `__cdecl` adalah standar untuk program C/C++, sementara `__stdcall` adalah standar wajib untuk seluruh Windows API (seperti MessageBox).
