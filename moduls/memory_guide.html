Kalkulasi Virtual Address (VA Absolute)

OS memetakan Raw Address dari disk ke lokasi virtual baru menggunakanRVA (Relative Virtual Address). Rumusnya:

VA = ImageBase + RVA

Contoh pada instruksi.text:0x00400000 + 0x1000 =0x00401000. Inilah alamat yang akan dilihat oleh debugger (Dynamic Analysis)!

Misteri Padding (Virt Size > Raw Size)

Ukuran di disk (Raw Size) seringkali lebih kecil dari memori yang dialokasikan OS (Virt Size). Kasus ekstrem ada di.bss(Variabel global tanpa nilai awal).

Karena isinya hanya 0, kompilator menghemat ruang disk dengan memberikanRaw Size = 0. Saat runtime, OS akan mematuhiVirt Size (0x2000)dan mencetak ruang RAM kosong yang di-isi-nol (Zero Padding).
